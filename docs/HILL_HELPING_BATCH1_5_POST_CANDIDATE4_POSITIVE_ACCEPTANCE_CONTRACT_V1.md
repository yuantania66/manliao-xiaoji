# 批次 1.5 候选 4 后续通用修改正向验收合同 V1

状态：2026-08-03 冻结于代码修改前

## 1. 范围与不变量

本合同只处理候选 4 分层归因确认的四类通用偏差：

1. 普通修复的组合式功能判断；
2. 当前轮情绪证据的自然派生表达；
3. 已知当前内容与未知其他内容／原因事件的作用域边界；
4. Surface 与 regeneration 对所选动作范围的稳定保持。

不修改 Safety、直接回答、暂停、Grounding、消息提交边界、Hill 决策或批次 2；不修改
原冻结数据、SHA、60 轮规模和通过阈值；不以候选 4 的单句输出建立专用分支。

## 2. 合同一：普通修复的组合式功能判断

### 2.1 正向功能

Validator 必须根据三个同时成立的关系判断 `interaction_move_withdrawal`：

1. **承担关系**：回复把问题归于 Assistant 的相邻目标行动或措辞；
2. **目标证据关系**：回复通过子类型语义或 `targetText` 中的具体动作证据，指向被用户
   拒绝的同一互动动作；
3. **功能性否定关系**：回复明确把该动作标为不应发生、越界、无效、偏离重点或本轮
   不再推进的动作。

三项关系可以使用自然语序组合完成。不得同时要求固定“停止／撤回／不再”词和固定
子类型词。`targetText` 中的“列方案、认真听、勇敢一点、呼吸放松”等具体证据可以在
自然形态变化后完成目标指向。

### 2.2 负向边界

以下仍必须拒绝：

- 只有“抱歉、越界、没接住、说偏了”，没有可识别目标动作；
- 指向了另一个子类型；
- 只重复原动作或承诺以后会做得更好，没有功能性否定；
- 自我辩护、归咎用户、要求用户诊断错误；
- 修复后继续推进被拒绝的建议、问题、套话、评判或话题切换。

### 2.3 完成门

- 候选 4 中已归因为 `validator_false_positive` 的普通修复全部接受；
- 候选 4 中真实空泛修复继续拒绝；
- 五个修复子类型各有独立正例和错目标／空泛反例；
- 不新增按候选句子逐字匹配的例外分支。

## 3. 合同二：当前轮情绪证据的自然派生表达

### 3.1 正向功能

Validator 必须以 Planner 合同中的 `affectEvidenceSpans` 为唯一语义来源，并允许不改变
类别、强度和作用对象的自然派生形式，例如：

- 原文程度副词的保留、省略或位置变化；
- “心里有点堵”到“心里这点堵／这股堵着的感觉”；
- 同一类别的常见词形变化，而不是要求回复包含完整原始连续字符串。

自然派生只解决回复侧等价判断，不得让 Validator 自行添加新的情绪类别或强度。

### 3.2 负向边界

以下仍必须拒绝：

- 用焦虑、恐惧、痛苦、抑郁、崩溃等不同类别替换用户原词；
- 将低强度提升为中高强度；
- 只使用“这种时候／这种情况”而没有情绪或关系影响指向；
- 以泛化安慰、解释原因或事件评价冒充承接。

### 3.3 完成门

- 候选 4 `emotion-vague-blocked` 中“心里堵着／这股堵”不得再被判为无承接；
- 类别替换和强度升级反例继续拒绝；
- 实现读取 Planner 的规范化证据类别，不建立新的候选专用短语白名单。

## 4. 合同三：当前内容作用域

### 4.1 正向功能

`return_focus_control` 的可选焦点必须能回指当前用户已经表达的情绪、关系影响、时间、
作用对象或已知部分。自然的“这一刻／这份感觉／其中哪一点／表达方式”可以属于当前
作用域。

### 4.2 负向边界

以下表达即使带有“你可以／由你决定”，也不能冒充当前焦点控制：

- 未限定的“别的什么／其他事情／不相干的内容”；
- 换轻松话题、转移注意力或换心情；
- 用户未提供的其他原因、事件或“还有什么让你……”；
- 默认追问刚才发生的具体事情。

Validator 必须在同一输出中独立报告功能完成与作用域越界，不能为了降低误拒而放开
未知内容。

### 4.3 完成门

- 候选 4 中 5 个 `surface_failure_validator_false_negative` 的第二次输出全部拒绝；
- 被当前情绪范围明确修饰的“别的方面”与无范围的“聊聊别的什么”必须得到不同判断；
- 当前内容正例与未知内容、原因事件、转移注意力反例同时通过。

## 5. 合同四：Surface 与 regeneration 动作范围保持

### 5.1 正向功能

Surface Prompt 必须把“完成所选正向功能”和“保持当前作用域”写成同一个生成义务。
regeneration 指令必须针对真实失败关系说明需要删除的动作，同时保留已经完成的功能，
不得只要求替换一个失败词。

对于情绪支持：

- 焦点控制只允许当前已知内容；
- 减负只移除分析／组织负担，不自动增加暂停、沉默或结束；
- 不用其他话题、调节或安慰替代支持功能。

对于普通修复：

- 必须用目标证据说明被拒绝的具体动作；
- 自然承担和功能性否定即可，不要求输出内部子类型名；
- regeneration 不得强迫模型机械加入固定“建议／话题切换／停止”词。

### 5.2 完成门

- Prompt 投影断言包含当前作用域和目标证据义务；
- regeneration 对 topic scope、unsupported event/affect、pause、normalization 和五类修复
  子类型给出功能性修复指令；
- 候选 4 的 30 次再生成按冻结归因重放：误拒改为接受，漏放改为拒绝，真实失败继续拒绝；
- 不能通过删除边界或整体放宽 Validator 降低再生成率。
