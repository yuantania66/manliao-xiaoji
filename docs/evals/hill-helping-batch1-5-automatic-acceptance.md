# Hill 助人过程批次 1.5 自动验收报告

状态：2026-08-02 初始自动验收曾通过但人工盲审未通过；新增多次运行质量保留门后候选 1、候选 2、候选 3 均未通过，仍停留在批次 1.5

## 1. 验收范围

本批只实现 `uncertain` 到普通聊天的受控交接：Helping Logic 提供适用性边界，
Conversation OS Response Planner 根据当前对话状态选择普通动作。它不启用用户可见
Hill 目标或技术，不写入 `CommittedHelpingMove`，也不增加第二个
`ResponsePlan`。

候选能力由默认关闭的 `HILL_HELPING_ORDINARY_HANDOFF` 控制。完整 Hill Shadow
仍由 `HILL_HELPING_SHADOW` 独立控制；仅启用批次 1.5 时，非快速边界话轮不调用完整
Hill provider。

## 2. 根因与修改点

批次 0 的真实产物表明，低信息数字话轮被正确识别为证据不足，但普通 Planner 在
`developing_thread + shared initiative` 且没有更高优先级义务时，仍统一选择
`acknowledge_without_psychologizing`。Surface 和 Validator 又允许“收到。”完成该
计划，因此多轮没有新增会话功能。

本批把修复放在拥有普通动作选择权的 Conversation OS：

- Helping Logic 只输出 `uncertain` 边界，不选择普通动作；
- Planner 在已有回答框架、已有语义话题、用户边界和上一已提交动作之间选择普通
  交接动作；
- Validator 按会话功能拒绝纯确认、纯在场和开放式“有事再说”，而非按固定字符串
  判重；
- 没有语义证据时不得猜数字、单字、表情或短消息的含义；
- Safety、直接回答、暂停、Grounding、当前话题、情绪和修复优先级保持硬门。

确定性测试已通过：

- 独立 held-out `啊 / 哦 / 哈 / 7 / 9` 通过；
- 重复轮的功能序列为“低压力校准 → 中性会话入口 → 低压力校准”，没有连续提交
  同一种无功能承接；
- Safety、直接回答、暂停、Answer Frame、Grounding、当前话题、情绪、行动和修复
  硬门通过；
- 关闭批次 1.5 标志时保留原基线行为；只启用批次 1.5 时不调用完整 Hill provider。

## 4. 人工盲审冻结

人工界面逐组显示一个 X/Y 对，要求选择两侧的绝对通过、适当结果、愿意继续、严重
失败，以及成对偏好和明显更差侧。全部 12 组完成后才生成冻结 JSON。界面不包含
来源、模型、Prompt、版本或密钥。

密钥承诺 SHA-256：

`92961bacb4ce21c1eab137bf44f8c63a67bae29f5e93b614d6ceca29f041aac3`

在读取人工答案前冻结的候选通过阈值：

- `absolutePass` 至少 11/12；
- `appropriateConversationOutcome` 至少 11/12；
- `wouldContinue` 至少 11/12；
- `clearlyWorse` 最多 1/12；
- 严重失败为 0。

揭盲程序还会验证人工答案是在读密钥前冻结、密钥 SHA-256、两份原始产物承诺、
样本完整性和全部评分字段。人工评分不会被程序修改。

## 6. 多次运行质量保留门

人工盲审失败后，没有针对 12 条文案修补。批次 1.5 新增 20 个合成场景、每场景
3 次的冻结质量保留门，覆盖情绪支持和有明确相邻上下文的普通关系修复。2026-08-02
使用 Qwen `qwen3.7-max` 完成 60 轮候选 1 运行，结果为最终有效 59/60、约束
失败 1、再生成 14/60；没有达到 100% 最终有效、0 约束失败和不高于 20% 再生成
的冻结阈值。

审计确认 Planner 会在修复状态下并发派发情绪/行动支持，且 Surface/Validator 对
公式化在场、泛化安慰、未经请求的调节、默认原因追问和无证据情绪强化约束不足。
代码已按通用动作与输出合同修正，并通过 36 个新增拒绝反例和相关本地回归；候选 1
保持失败。修正后的候选 2 使用同一冻结数据和阈值完成 60 轮，结果仍为最终有效
59/60、约束失败 1、再生成 25/60，因此同样失败。没有生成盲审候选。完整证据见
[批次 1.5 情绪与关系修复质量保留门](./hill-helping-batch1-5-preservation-gate-20260802.md)。
