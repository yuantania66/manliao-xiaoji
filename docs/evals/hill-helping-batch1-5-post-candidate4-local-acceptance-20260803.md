## 根因与实现

1. 普通修复 Validator 仍把目标证据和功能性否定当成有限固定词组合，导致自然的
   “空话代替回应重点”“没有接你的重点”等表达被误拒。实现改为验证承担、相邻目标证据、
   功能性否定三项组合关系，保留五种互动目标子类型边界。
2. 回复侧情绪派生没有完整复用 Conversation State 的规范化证据，导致“心里这点堵”等
   同类别形态被误拒。实现统一通过 `extractAffectEvidence` 比对类别和作用对象，并保留
   明确强度升级与类别替换拒绝。
3. 作用域 Validator 没有独立覆盖无关内容、同义转移注意、未知原因／事件，导致已完成
   焦点控制的回复仍可夹带范围外动作。实现新增独立失败关系和对应再生成指令。
4. Surface/再生成边界对同义暂停、腹式呼吸、自然化话术覆盖不足。实现保持所选支持动作，
   独立拒绝额外暂停、调节和泛化正常化，不通过删除边界降低再生成率。

Prompt 版本由 `chat-response-plan-v23` 升为 `chat-response-plan-v24`。
