## 2. 总判断

Hill 与心理学相关能力是慢聊的**专业上限**；普通可聊是**生存下限**。

- 第 6 版把探索 / 领悟 / 行动视为**流动目标族**，不是用户必须依次通过的固定阶段机。
- 大量慢聊话轮应得到 `not_applicable` 或普通聊天，而不是每句都上助人话术。
- 在可聊性未稳住前加厚心理学表层（采访、因果解读、未请求建议），会拖累整体体验。

优先级：

```text
① 普通可聊下限
  → ② 适用性 + 探索低负担 + 修复/伦理
  → ③ 领悟 / 行动（有准备度才开）
  → ④ 更细技术菜单与长期评估
```

## 3. 必做

| 书里的东西 | 产品对应 | 为什么必做 |
|---|---|---|
| 助人适用性 | `applicable` / `uncertain` / `not_applicable` | 乱上助人会变成采访或心理化；不适用时应走普通聊天 |
| 回合环：意图 → 技术 → 看反应 → 再决策 | Helping 闭环 + 上一招评估 | 否则每句像新开咨询，没有“上一句有没有用” |
| 探索：倾听、复述、低负担支持、少追问 | 情绪陪伴默认落在探索 | 最贴“愿意继续聊”；也最容易被过度实现搞砸 |
| 关系与修复 | 误解、否认、关系紧张时的修复 | 真实会话里伤信任的多是这类，不是缺高阶技术 |
| 伦理边界 | 不诊断、不强加价值、Safety 优先 | 产品红线；比任何技巧都重要 |
| 用户意义解释权 | 猜测可撤回、不固化标签 | PRD 核心；心理学“解读”最容易踩 |

## 4. 可延后

| 书里的东西 | 产品对应 | 延后条件 |
|---|---|---|
| 领悟：挑战、解释、关系加工 | 仅在准备度证据足够时 | 用户未展开、负担高、在纠错时禁止 |
| 行动：信息、决策支持、行为演练 | 用户明确要下一步时 | 未请求就给建议或练习属于已见失败模式 |
| 文化谦逊 / helper 自我觉察 | 内部约束，不展示给用户 | 先做成 fail-closed 规则，不做人格戏 |
| 完整技术菜单 | 内部枚举，不向用户曝光标签 | 先少而稳，再加技术种类 |
| 长期助人轨迹评估 | 跨会话效果 | 依赖记忆与隔离，独立待办 |

## 5. 禁止产品化

| 书里或心理学常见做法 | 产品禁令 | 原因 |
|---|---|---|
| 把用户推进固定“阶段” | 不做线性阶段机 | 第 6 版已改为目标流动 |
| 对用户展示“我在用某某技术” | 不展示 Hill / 疗法标签 | 契约已写；破坏自然聊天 |
| 诊断、评估、治疗计划、量表报告 | 明确非目标 | 不是医疗产品 |
| 完整 CBT / ACT / MI 临床策略 | PRD 非目标 | 会把慢聊拖成伪咨询 |
| 未请求的放松 / 呼吸 / 正念 | 默认禁止；是否永久禁止仍属开放产品题 | 真实失败模式；C 类门禁未关单 |
| 擅自强化情绪（如“有点孤单”→“挺磨人”） | 应拒绝 | 冻结归因中的真缺陷 |
| 因果心理化、连续采访式追问 | 普通回答后默认不追问 | 已验证伤体验 |
| 用人格画像定义用户 | 禁止 | PRD 定位 |

## 6. 心理学在产品中的摆放

```text
心理学 / Hill
  → 内部决策与边界（何时助人、助到哪、何时退出）
  → 不是对外话术风格，也不是每句都要“像咨询师”

普通可聊（承接、不刷屏、计划不自相矛盾）
  → 生存下限；没有它，上面全部无效
```
